# Utils

Esta carpeta contiene funciones pequeñas y reutilizables que no dependen del DOM ni de una pantalla.

- `fechas.js`: fechas y formatos de fecha.
- `horarios.js`: horas, rangos y solapamientos.
- `texto.js`: normalización de texto y códigos de asignatura.

Si una función necesita conocer una funcionalidad concreta, probablemente debe vivir en el módulo correspondiente.
