# Core

El core conecta las piezas principales de la aplicación.

- `app.js` carga los datos, crea el estado y arranca los módulos.
- `config.js` define las rutas y opciones de la aplicación.
- `constants.js` contiene valores compartidos y estables.

Aquí se coordina el flujo general. No pongas reglas específicas de una funcionalidad ni código de estilos.
